A few things you should know before diving in:

Gnat is early software. Some features may not work as intended, and you may run into rough edges, incomplete functionality, or unexpected behavior. This is the nature of a project at this stage.

No warranties are expressed or implied. Use it at your own risk.

Heads up: the entire project will likely break the moment the game receives a title update. Anti-cheat and game binaries change frequently, and there's no guarantee of a timely fix — or any fix at all.

How to use it:

Download the release package.

Launch the server.

Back up EAAntiCheat.GameServiceLauncher.exe, then swap in the community-recreated version included in the release archive.

Drop dinput8.dll into your game directory.

Start the game.

The general settings panel opens with F7; recording starts and stops with F6.

While recording is running, matches are automatically saved to a local scratch space in your Documents folder. With the server live, you can review those captures from any device on the same local network — phone, laptop, or anything else.

Note: To go online again, delete dinput8.dll from the game directory and restore the original EAAntiCheat executable.
